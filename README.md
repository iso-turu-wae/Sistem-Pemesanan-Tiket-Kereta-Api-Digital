# Project akhir

**Sistem Pemesanan Tiket Kereta Api Digital**
Program berbasis terminal yang dibuat menggunakan Python untuk membaca, menampilkan, menambahkan data, top up saldo, reschedule tiket dan cetak invoice untuk pemesanan tiket kereta api digital. Data disimpan dalam file `json`, sehingga dapat digunakan kembali setelah program ditutup
